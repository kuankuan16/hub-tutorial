TENTEN · 專案管理

專案管理新手教學

網站打開之後照這頁做：先看懂畫面，再把自己電腦裡的專案放進去，最後開始用它工作。大約 5 分鐘。

  • 一先看懂畫面
  • 二把自己的專案放進去
  • 三開始工作

一、先看懂畫面

圖裡的橘色編號，對應圖下面的說明。

  1. 1

    打開網站

    在瀏覽器打開下面這個網址。它只在你自己的電腦上，別人打不開你的。

    http://127.0.0.1:3939/

    打不開的話，到下載的資料夾（通常是 ~/Projects/tenten-project-hub）雙擊「啟動專案管理」。

  2. 2

    macOS 問能不能讀資料夾，按「允許」

    第一次找專案時，Mac 會跳出好幾個這樣的視窗，問能不能讀「文件」「桌面」等資料夾。每一個都按「允許」，全部按完再按一次「更新清單」。

    「node」想要取用「文件」檔案夾中的檔案。
    不允許允許

    示意圖，實際文字依 macOS 版本略有不同。

    不小心按了「不允許」

    打開「系統設定 › 隱私權與安全性 › 檔案與資料夾」，把「node」（或「終端機」）底下的開關都打開，再回網站按「更新清單」。

  3. 3

    看懂一張卡片

二、把自己電腦的專案放進去

大部分的人打開就已經看到自己的專案了。先看看網站會自動去哪裡找，少了再自己加。

網站會自動找這些地方

~/Projects、~/Developer、~/Documents（文件）、~/Desktop（桌面）、~/code、~/Sites、~/GitHub，每個往下找 3 層，資料夾存在才會找。

什麼樣的資料夾算一個專案：裡面有 .git（用 Git 管理的），或有 AGENTS.md、CLAUDE.md、.codex、.claude（用過 AI 的）。

網站只會讀，不會搬動或修改你的任何檔案。

  1. 4

    專案放在別的地方：打開「掃描設定」

    按左下角的「更多」，再按「掃描設定」。

  2. 5

    在「專案根目錄」加一行

    每行寫一個要找的資料夾，可以用 ~/ 開頭（代表你的個人資料夾）。例如專案都放在 ~/Work，就在最後加一行 ~/Work。

    不知道資料夾的路徑？

    在 Finder 對那個資料夾按右鍵，再按住 Option 鍵，選單裡會出現「拷貝…路徑名稱」，按它，再貼到這裡。

  3. 6

    按「儲存並同步」

    按視窗最下面的「儲存並同步」，網站會馬上重新找一次。

  4. 7

    新的專案出現了

    剛剛加的資料夾裡的專案，會變成新的卡片。卡片上會寫它在哪裡，例如 Work › spring-campaign。

還是沒出現？

  • 資料夾裡沒有 .git 也沒有 AGENTS.md：網站認不出來它是專案。把下面這句貼給 Claude Code 或 Codex，換成你的資料夾，再按「更新清單」。
請在（貼上資料夾路徑）建立一個 AGENTS.md，用一句話寫這個專案在做什麼。
  • 放得太深：網站只往下找 3 層。直接把那個專案的上一層資料夾加進「專案根目錄」最快。
  • macOS 沒有允許讀取：照第 2 步「不小心按了不允許」的做法打開。
  • 不想看範例：在「專案根目錄」刪掉最後是 examples 的那一行，按「儲存並同步」。

三、開始工作

專案都在了，之後每天只會用到「寫下一步」「開工」「收尾」。

  1. 8

    替常用的專案寫「下一步」

    按卡片上的鉛筆，在「下一步」寫接下來要做的事，按「儲存變更」。它會顯示在卡片上，下次打開一眼就知道做到哪。這些只存在網站裡，不會改到專案資料夾。

  2. 9

    開工：按「接著做」，再選要用的 AI

    按卡片的「接著做」打開維護單，在「開工」選一個 AI。網站會在這個專案資料夾打開 Warp，並把啟動指令和開場要說的話複製好。到 Warp 按 ⌘ V，再按 Enter。

    沒有裝 Warp：維護單下面每一行指令都有「複製」，貼到自己的終端機就好。

  3. 10

    收尾：按「複製收尾的話」貼給 AI

    做完一段工作，在同一張維護單往下捲到「收尾」，按「複製收尾的話」貼給 AI。它會照順序更新交接文件、存版本、備份；要刪除、覆蓋或更新網站之前，會先問你。

還沒安裝？

電腦要有 Node.js 20.14 以上和 Git，GitHub 帳號要在 Tenten 的 GitHub 裡。打開 Claude Code 或 Codex，貼上這句：

請把 https://github.com/tentenco/tenten-project-hub 下載到 ~/Projects/tenten-project-hub，在那個資料夾執行 npm install 和 npm run build，再執行 npm run dashboard:install 讓它開機自動啟動，最後幫我打開 http://127.0.0.1:3939/。

專案卡、Prompt、筆記都只存在自己的電腦，不會上傳，也不會進 Git。看不懂哪一步，直接問分享這頁給你的人。
